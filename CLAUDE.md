# Trade Shark — notes for Claude

- **Single seller, fun collector shop.** This is one person's cute card shop (tone: light, friendly, never investment talk). Don't add signups, seller accounts, teams, billing, roles, or "sell on our platform" copy. Public pages speak as one shop ("my shop"), never imply other sellers. A future multi-seller split may change the folder layout; don't build toward it.
- **The shop publishes itself; marketplaces never do.** On upload (`lib/publish.ts`, run from `processBatch`): no name or no photo → hold in Inbox (never invent a name; a filename guess isn't a name); under $1 → Lil' Stack; $1–$5 → **For Sale** (status `Ready`) with its pay link created first; over $5 → **Needs a look** (`NeedsLook`) until the owner approves or corrects it in `/admin/queue`. The $5 line is dollars, not confidence: uncertain prices still publish. Nothing ever posts to eBay, TCGplayer or anywhere else: exports are draft CSVs the owner publishes by hand.
- **Stripe is the direct-buy path.** Saving a card into Ready/Listed creates its Payment Link first (`lib/payLink.ts`); if Stripe fails the card stays Priced. One link per card (or per Lil' Stack), quantity 1, single completed checkout. Regenerating expires the old link first. A card or pack becomes Sold only from the signed webhook (`/api/stripe/webhook`, matched by current or previous link id) or by hand, never from the thank-you redirect. No carts, buyer accounts, or subscriptions.
- **Price rule** (`suggest` + `shopPrice` in `lib/pricing/engine.ts`): one headline per source (sold-comp median, TCGplayer market, Scryfall ask, eBay active median), then the median of those; one source = that number; none = $1. Round to the nearest dollar, min $1; under $1 stays exact (Lil' Stack). Sources and disagreement are stored on the card, never shown on the shop (the disclaimers cover it).
- **Buyer shipping** (`lib/shipping.ts`, rates in Settings → `buyerShipping`): added on top of the price as its own Payment Link line ("Stamped envelope" / "Tracked bubble mailer"), never baked into the card or pack price. Raw single under $20 → envelope (unless the card's shipping profile is bubble/slab); graded, $20+, or any Lil' Stack → mailer; single card at/over the free cutoff ($35) → free. Never free shipping on a Lil' Stack, no low-threshold unlocks. Show cards, shipping and total before every buy button. The webhook stores `shippingCharged`, `shipMethod` and `shipTo` on the order; `soldPrice` is merchandise only.
- Public pages read cards only through `PUBLIC_CARD_SELECT` (no cost, margin, comps, notes, or Stripe ids). Every card and pack page shows the four disclaimers (`lib/disclaimers.ts`).
- Copy: titles plain; descriptions short and friendly (`friendly()` in `lib/listing/templates.ts` drops any sentence with investment, gem-mint or guarantee talk).
- **Lil' Stack** (`lib/lilStack.ts`): cards under $1.00 never sell as singles. After a batch is priced they go into packs (one batch per pack, max 12, a card in one pack only, status `LilStack`). Repricing to $1+ pulls a card out. Rebuilds are stable: unchanged packs keep their link.
- Opening a pack is always free and shows every card. Buy this stack appears only after the swipe. One Payment Link per pack (`Lil’ Stack, Trade Shark`, card names in the description), price = sum of list prices rounded up to the dollar, min $3. No fee line, no odds, no paid reveal. Sold packs leave `/lil-stack`; Shuffle skips them. Public pack data only via `publicPacks()` (id, name, set, pack price).
- Pack art comes from Gemini (`lib/brandArt.ts`) using `GEMINI_API_KEY` on the server only, from a text prompt. Never send card photos to it. Cached in `DATA_DIR/brand` / bucket `brand/`; missing key = CSS pack, never a broken page.
- **Home ranks by wow, never price** (`lib/wow.ts`, `lib/home.ts`): art/numbered +40, chase list (Settings) +25, graded 9–10 +20, newest set in the batch +10; a Featured pin (one card or one pack) beats it. Price only on the button and as secondary text. `/shop` and `/lil-stack` may sort by price.
- Delight (`lib/client/feel.ts`): one short pop on primary buttons, confetti only when a card goes live, sells, or a Lil' Stack is torn open. Respect the Mute toggle and prefers-reduced-motion; never block a save on it.
- **Add price/identity sources as adapters** in `lib/sources/` (`IdentifyAdapter` / `PriceAdapter` in `lib/sources/types.ts`), registered in `lib/sources/index.ts`. Adapters fail soft: return `{ status, reason }`, never throw, and skip cleanly when their env key is missing.
- Keep junk out of medians: comps go through `filterComps` (excluded rows are kept and labeled, not deleted). Retail asks (Scryfall, eBay active listings) are their own headlines, never mixed into sold comps.
- Every quote is persisted (`PriceQuote`); only the latest fetch per source drives the suggestion. Manual override always wins.
- Confidence is stored (and highlighted in review) but no longer gates publishing; only a missing name holds a card.
- Scans are private: serve them only via `/api/admin/images/*` (auth) or `/api/shop/image/*` (for-sale cards only).
- No league, Pokémon, Nintendo, Disney, or other third-party logos in the brand. Colors: navy `#0B1F3A`, teal `#1AA6A6`, sand `#F4EFE6`, coral `#E85D4C`, white.
- Data: Supabase Postgres, schema `trade_shark` (Prisma), and the private `trade-shark-scans` bucket via `lib/storage.ts`. Hosting: Netlify — keep each request short (one card per process call) and send large uploads straight to Storage.
- **Auto-orientation** (`lib/orient.ts`, the first step of `processBatch`, one card per request): every crop is stood upright before identify/price/publish. The vision model says which image edge is the card's top, then re-checks the turned image; the same turn goes to the back; the fixed image is saved over the crop (original kept only for a guess). Without a vision key: landscape crops get a layout guess and wait in Needs a look; portrait is never flipped. Anything still sideways → `holdReason: "rotation"` → Needs a look, never published sideways. Each crop is turned on its own, never the whole sheet. Hand rotation (flatbed "Fallback" panel, queue ↻ buttons, `/api/admin/cards/:id/rotate`) is admin fallback only.
- Flatbed split runs client-side with opencv.js (`lib/flatbed/*`, served from `public/vendor` by `scripts/copy-opencv.mjs`). Never send a whole flatbed sheet to a vision API to split it. Front/back crops pair only by sheet position with identical layouts (`checkSheetPairing`); never guess pairs.
- Checks: `npm test` and `npm run lint` (tsc). Schema changes: edit `prisma/schema.prisma`, run `npx prisma db push` (uses `DIRECT_URL`).
