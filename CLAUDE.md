# Trade Shark — notes for Claude

- **Single seller, fun collector shop.** This is one person's cute card shop (tone: light, friendly, never investment talk). Don't add seller accounts, teams, logins, roles, or "sell on our platform" copy. Behind the scenes three partners (Matthew, Adrian, Mike) own the cards and get paid out (see Partners); that is admin-only, and public pages still speak as one shop ("my shop"), never imply other sellers. The only player identity is the pack game's `Buyer` (a guest until the first Keep, then a Stripe customer + saved card; signed `ts_player` cookie, no password); the only subscription is the optional membership. A future multi-seller split may change the folder layout; don't build toward it.
- **Packs only; marketplaces never post.** The shop has three products: Baseball Pack, Football Pack, Pokemon Pack (`lib/categories.ts`; no basketball, no Magic, one tier each). The public shop shows only `PUBLIC_CATEGORIES` (Pokemon for now; baseball and football come back by adding them to that list once stocked, no admin setting); other `/packs/<category>` URLs redirect home and the play API refuses them. The desk still uploads, prices and builds all three. Cards never sell as singles on the site (the one exception is the founder's eBay lane below). On upload (`lib/publish.ts`, run from `processBatch`): no name or no photo → hold in Inbox (never invent a name; a filename guess isn't a name); $5 and under → stock (`Priced`); over $5, still sideways, or the same scan twice → **Needs a look** (`NeedsLook`) until the owner approves it in `/admin/queue` (approve = back to stock). The $5 line is dollars, not confidence. Nothing posts to TCGplayer or anywhere else on its own (exports are draft CSVs the owner publishes by hand); the only marketplace post is the eBay lane, and only when the founder presses its button.
- **eBay lane** (`lib/ebay/seller.ts`, desk section "eBay lane", `/api/admin/ebay/connect` + `/callback`, desk actions `ebay-list`, `ebay-sync`, `ebay-disconnect`): nothing lists until the eBay seller login is connected (OAuth with `EBAY_CLIENT_ID`, `EBAY_CLIENT_SECRET`, `EBAY_RUNAME`, server only; refresh token in Setting `ebay:seller`; the RuName's accept URL is `/api/admin/ebay/callback`). The card is claimed first (status `Listed`, `listedChannel` ebay) so no pack can take it; any eBay error puts it back in stock with `ebayError` and the desk lists it. The tick reads Fulfillment orders every 5 minutes (`syncEbaySales`): a sold sku → status Sold, `soldChannel` ebay (shown as sold-ebay), never packed or peeked; the desk shows its slot code to pull and ship. Unsold eBay listings are not ended automatically.
- **The pack game is the only checkout** (`lib/game/*`, `/packs/[category]`, `/api/play/*`). Rules sentence (`RULES_LINE`: "Looking is free. Three looks a day. The first is $3.99 to keep, the next is $4.99, the last is $5.99.") and odds (`oddsLines`) are on screen before the first look. Looking never costs money: no reveal charge, no paid extra look, no card needed, a signed-out visitor can look (a guest `Buyer`, `stripeCustomerId` "guest_…", made on the first look). The button carries the keep price of the look about to be taken: "Show me the cards · $3.99 to keep" (`/api/play/look`): a ready pack is reserved and all 12 cards are shown with engine prices; 120 s server deadline (+3 s grace), shown in small navy type, no red, no nudge. Keep price ladder (`KEEP_LADDER`, `keepPriceFor` in `lib/game/rules.ts`, used by page and server): look 1 of the local day in a category $3.99, look 2 $4.99, look 3 $5.99; a new local day starts over. It is stored on the cycle when the pack is shown (`GameCycle.lookNumber`, `keepPrice`); Stripe charges that stored price and no other, and a Keep sending any other amount is refused (`keepCharge`); the client never picks it. The open pack's Keep button shows the stored price, large; looks 2 and 3 after a pass may add, small, "You put one back, so this one is a dollar more." After a pass the next pack never opens in the same tap: a ~1 s navy-and-gold beat shows the price passed, the next price, the three steps (1 · $3.99, 2 · $4.99, 3 · $5.99) with the current look lit and "That one went back. This one is a dollar more.", then "Show me the next one · $4.99 to keep" (or $5.99). Keep = one charge of the stored price, no shipping: a saved card is charged off-session; the first time, Stripe Checkout (payment mode, `setup_future_usage`) takes the stored price and saves the card with that payment (pack held while Checkout is open; `/api/play/kept` and the webhook finish it via `completeCheckout`; a payment that lands after the pack went back is refunded). Put them back (Pass) or the timer puts the cards back (stock, redrawn) and never charges; nothing locks. Leaving the page is not a pass. Cap: `LOOKS_PER_DAY` (3) looks per category per local day for the account and its card fingerprint (`Buyer.tz` / browser zone), plus `LOOKS_PER_DAY_PER_IP` per hashed network address; each look writes a `GameLock` row (the look ledger) ending at local midnight. "Dealer's choice · $6.99" (above the last look) is an optional quiet text link for players with a saved card: charge first, reserve from the same queue, show, no reject; never the only button after a pass. One active look per account. Off-session PaymentIntents on the saved card, every attempt in `GameCharge`, idempotency key = cycle + kind + attempt; a charge taken with no pack to give is refunded. Payment Links are retired (`retireOldLinks`); the webhook matches old links, Keep checkouts (metadata kind "keep") and membership events.
- **Price rule** (`suggest` + `shopPrice` in `lib/pricing/engine.ts`): one headline per source (sold-comp median, TCGplayer market, Scryfall ask, eBay active median), then the median of those; one source = that number. CardSight names the card (it returns no price today). When the sources give a named card no price, the fallback chain asks in order and stops at the first price (`FALLBACK_PRICE_SOURCES`): **PriceCharting** for all three categories (Pokemon on pricecharting.com: exact name + number, base before reverse holo unless our card names the parallel, set name breaks ties, Chinese prints only from Chinese sets), then for Pokemon the TCGplayer market (pokemontcg.io) and **JustTCG** (name + number, Near Mint normal print, `JUSTTCG_API_KEY`). PriceCharting for sports (its SportsCardsPro API, same token; player + year + set + `#number`, ungraded price only for a Football/Baseball Cards set with the same last name and exact number, base card or our named parallel, one set; never a Funko or other product, `PRICECHARTING_API_KEY`); a missing key skips it, a match it can't confirm is no price. After a key is added, `POST /api/ingest/reprice?since=<iso>` (x-ingest-key) runs the unpriced named cards through the sources once, a few per call. Still nothing = **unpriced** (`listPrice` null, status Identified): never $1, $0 or any default. Unpriced cards stay out of packs and sit in the desk's **Unpriced** column (tray U) with a box to type a price (a manual price, which bins the card normally). Round to the nearest dollar, min $1; under $1 stays exact. The game never prices a card: pack value = sum of the cards' existing `listPrice`. Sources and disagreement are stored on the card, never shown on the shop (the disclaimers cover it).
- **Collection + shipping** (`lib/game/ship.ts`, `/collection`, `/api/play/collection/:id`, `/api/play/ship/*`, `lib/ship/shippo.ts`): buying a pack never ships it or charges shipping. Never auto-ship. Shippo rate fails → flat $5.95 and I buy the label from the order. From 1424 Orchid Lane, Kissimmee, FL 34744, one service only. The member mailer credit zeros one parcel per period.
- **Owners, payouts, reserve** (`lib/partners/*`, `/admin/partners` "Payouts", `/consign`): every card is tagged before it can enter a bin: a founder (`Card.partnerId`: Matthew, Adrian, Mike) or a consignment sender (`Card.senderId`, `Sender`). Tag on upload (`createBatch(name, "f:<id>" | "s:<id>")`, required), per batch, or per card. Stacks copy `partnerIds` / `senderIds`; packs mix owners. On a completed keep or blind buy (`recordSale`): founders split the amount actually charged (the cycle's stored keep price, or the $6.99 blind) − Stripe fee − stamp credit by engine value (`splitNet`, leftover cent to the largest share) → `PartnerEarning`; each consignment card owes its sender its engine price (`SenderEarning`, reserved → payable), not a share; the founders' unpaid remainder is company money → `ReserveEntry` "pack". The reserve (`ReserveEntry` ledger) is filled only by company money: membership invoices (`invoice.paid` webhook), the company part of packs, founder shares retained (`payPartner(id, {retain})`); sender payouts take from it. A stack with consignment cards is built only if `reserveNow().headroom` (on hand − payable − consignment already in stacks) covers all of them (`fitsReserve`); otherwise they wait in the hold bin. Payouts are manual Stripe Connect transfers of the payable balance. **Consignment is locked by default** (`Settings.consignOpen`): `/consign` shows Coming soon with no form, `/api/consign` refuses, admin can't accept requests, add senders, tag sender cards or pay senders, and the builder skips sender cards; locking dissolves ready stacks holding them. Shipping is never split; unsold cards and packs put back pay nothing.

Columns Bulk / Mid / Top / Hit / Unpriced / Hold / Energy with upright thumbnails. Energy (tray E, `isEnergy`: any card named Energy, basic or special) is a side bin and never goes in a pack. Unpriced = named and owned but no source priced it (type a price). Hold = needs a look, sideways (one-tap ↻ ↕ ↺ ✓ via `/api/admin/cards/:id/rotate?deg=`), no owner, chase while off, consignment. When no more legal packs can be listed, one line says what's missing. A pulled pack that comes back (pass, dissolve) lists its cards under step 2 to put back. - **Ingest is two steps** (`lib/ingestQueue.ts`): an upload (images, flatbed crops, PDFs) only stores the files and answers at once ("19 pages received.", `/api/admin/batches/:id/queue`). The work runs in the background, a unit at a time (`tick`): for each new file make its card → for each card `processCard` (orient → frame → identify the upright crop only → price → stock / Needs a look), so a card is in its bin as soon as it's priced. Ticks come from the open desk / batch page (`IngestTicker`, "4 of 19 priced") and from the scheduled Netlify function `netlify/functions/ingest-tick.mts` every minute (`x-ingest-key` = sha256 of `INGEST_KEY` or the admin password). - **Drive inbox** (`lib/ingestInbox.ts`, `POST /api/ingest/upload`, outside the admin session): a Google Drive script sends one file per request with `x-ingest-key` (same hash as the tick) and `?owner=matthew|adrian|mike&name=…` (raw body or multipart `file`, ≤ 5.5 MB). - **PDFs** (browser split: `lib/client/pdfSplit.ts`, server: `lib/pdf.ts`, `lib/pdfIngest.ts`): the admin's browser renders each page at 300 dpi with pdf.js (`public/vendor/pdfjs-<ver>/`, copied by `scripts/copy-opencv.mjs`); several cards → the flatbed detector (opencv.js) crops each; one card → the page is uploaded whole with `meta.trim` and the server's `trimToCard` (sharp) crops to the card's straight bounding box (border-strip background; a card-shaped page is kept whole; never turned a few degrees). Never put mupdf, opencv or other WASM on the server: the Netlify server function must stay under the 50 MB Lambda limit (it is about 49 MB). Each crop is a front scan tagged to the batch owner. Hand rotation (flatbed "Fallback" panel, queue ↻ buttons, `/api/admin/cards/:id/rotate`) is admin fallback only.
- Flatbed split runs client-side with opencv.js (`lib/flatbed/*`, served from `public/vendor` by `scripts/copy-opencv.mjs`). Never send a whole flatbed sheet to a vision API to split it. Front/back crops pair only by sheet position with identical layouts (`checkSheetPairing`); never guess pairs.
- Git: commit and push straight to `main` (no feature branches, no PRs). Live deploys go to Netlify from the session, not from GitHub.
- Checks: `npm test` and `npm run lint` (tsc). Schema changes: edit `prisma/schema.prisma`, run `npx prisma db push` (uses `DIRECT_URL`).
