# Trade Shark — notes for Claude

- **Single seller, fun collector shop.** This is one person's cute card shop (tone: light, friendly, never investment talk). Don't add signups, seller accounts, teams, billing, roles, or "sell on our platform" copy. Public pages speak as one shop ("my shop"), never imply other sellers. A future multi-seller split may change the folder layout; don't build toward it.
- **Packs only; marketplaces never post.** The shop sells three products: Baseball Pack, Football Pack, Pokemon Pack (`lib/categories.ts`; no basketball, no Magic, one tier each). Cards never sell as singles. On upload (`lib/publish.ts`, run from `processBatch`): no name or no photo → hold in Inbox (never invent a name; a filename guess isn't a name); $5 and under → stock (`Priced`); over $5, still sideways, or the same scan twice → **Needs a look** (`NeedsLook`) until the owner approves it in `/admin/queue` (approve = back to stock). The $5 line is dollars, not confidence. Nothing ever posts to eBay, TCGplayer or anywhere else: exports are draft CSVs the owner publishes by hand.
- **Stripe is the direct-buy path.** One Payment Link per pack (`<Product>, Trade Shark`, card names in the description), quantity 1, single completed checkout; created when the pack is built, replaced (old one expired first) when its cards or price change. Single-card links are retired (`/api/admin/cards/:id/paylink` returns 410; Ready/Listed can't be set). A pack and its cards become Sold only from the signed webhook (`/api/stripe/webhook`, matched by current or previous link id) or by hand, never from the thank-you redirect. No carts, buyer accounts, or subscriptions.
- **Price rule** (`suggest` + `shopPrice` in `lib/pricing/engine.ts`): one headline per source (sold-comp median, TCGplayer market, Scryfall ask, eBay active median), then the median of those; one source = that number; none = $1. Round to the nearest dollar, min $1; under $1 stays exact. **Pack price = the exact sum of its cards' list prices** (`packPrice`); no other pricing source, no rounding, no minimum. Sources and disagreement are stored on the card, never shown on the shop (the disclaimers cover it).
- **Buyer shipping** (`lib/shipping.ts`, rates in Settings → `buyerShipping`): its own Payment Link line, never baked into the pack price. Every pack ships in a tracked bubble mailer and never ships free. Show cards, shipping and total before every buy button. The webhook stores `shippingCharged`, `shipMethod` and `shipTo` on the order; `soldPrice` is merchandise only.
- Public pages read cards only through `PUBLIC_CARD_SELECT` (no cost, margin, comps, notes, or Stripe ids). Every card and pack page shows the four disclaimers (`lib/disclaimers.ts`).
- Copy: titles plain; descriptions short and friendly (`friendly()` in `lib/listing/templates.ts` drops any sentence with investment, gem-mint or guarantee talk).
- **Packs** (`lib/lilStack.ts`; tables/status keep the old Lil' Stack names, `LilStack` status = in a pack): a pack is exactly 12 cards of one category, built across batches, oldest first, a card in one pack only. `category` comes from `categorize()` over identification fields (Pokemon game → pokemon; sports by league words, full team names, then unique nicknames; ambiguous/basketball → null = unsorted, stays in inventory). A category set by hand (`categorySource: "manual"`) sticks. Builds (`buildPacks` / `rebuildAllPacks`, after every batch, reprice, and card save) are stable: unchanged packs keep their link; a short pack refills from stock or dissolves; extras wait in stock. The planner is pure (`planCategory`).
- Opening a pack is always free and shows all 12 cards (`/packs/[category]`). Buy this pack appears only after the swipe. No fee line, no odds, no blind packs, no paid reveal. Sold packs leave the page; Shuffle skips them. Public pack data only via `publicPacks()` / `catalog()` (id, name, set, pack price; never a card's own price).
- Pack art comes from Gemini (`lib/brandArt.ts`) using `GEMINI_API_KEY` on the server only, from a text prompt. Never send card photos to it. Cached in `DATA_DIR/brand` / bucket `brand/`; missing key = CSS pack, never a broken page.
- **Home is the catalog**: the three products with pack counts and price range (restocking when empty). `/shop` and `/lil-stack` redirect there; `/card/:id` is a 404. The wow score (`lib/wow.ts`) is an admin-only tag now; there is no hero or Featured pin.
- Delight (`lib/client/feel.ts`): one short pop on primary buttons, confetti only when a card is packed, a pack sells, or a pack is torn open. Respect the Mute toggle and prefers-reduced-motion; never block a save on it.
- **Add price/identity sources as adapters** in `lib/sources/` (`IdentifyAdapter` / `PriceAdapter` in `lib/sources/types.ts`), registered in `lib/sources/index.ts`. Adapters fail soft: return `{ status, reason }`, never throw, and skip cleanly when their env key is missing.
- Keep junk out of medians: comps go through `filterComps` (excluded rows are kept and labeled, not deleted). Retail asks (Scryfall, eBay active listings) are their own headlines, never mixed into sold comps.
- Every quote is persisted (`PriceQuote`); only the latest fetch per source drives the suggestion. Manual override always wins.
- Confidence is stored (and highlighted in review) but no longer gates publishing; only a missing name holds a card.
- Scans are private: serve them only via `/api/admin/images/*` (auth) or `/api/shop/image/:id/front` (cards in an open pack only).
- No league, Pokémon, Nintendo, Disney, or other third-party logos in the brand. Colors: navy `#0B1F3A`, teal `#1AA6A6`, sand `#F4EFE6`, coral `#E85D4C`, white.
- Data: Supabase Postgres, schema `trade_shark` (Prisma), and the private `trade-shark-scans` bucket via `lib/storage.ts`. Hosting: Netlify — keep each request short (one card per process call) and send large uploads straight to Storage.
- **Auto-orientation** (`lib/orient.ts`, the first step of `processBatch`, one card per request): every crop is stood upright before identify/price/publish. The vision model says which image edge is the card's top, then re-checks the turned image; the same turn goes to the back; the fixed image is saved over the crop (original kept only for a guess). Without a vision key: landscape crops get a layout guess and wait in Needs a look; portrait is never flipped. Anything still sideways → `holdReason: "rotation"` → Needs a look, never published sideways. Each crop is turned on its own, never the whole sheet. Hand rotation (flatbed "Fallback" panel, queue ↻ buttons, `/api/admin/cards/:id/rotate`) is admin fallback only.
- Flatbed split runs client-side with opencv.js (`lib/flatbed/*`, served from `public/vendor` by `scripts/copy-opencv.mjs`). Never send a whole flatbed sheet to a vision API to split it. Front/back crops pair only by sheet position with identical layouts (`checkSheetPairing`); never guess pairs.
- Checks: `npm test` and `npm run lint` (tsc). Schema changes: edit `prisma/schema.prisma`, run `npx prisma db push` (uses `DIRECT_URL`).
