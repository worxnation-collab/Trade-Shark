# Trade Shark — notes for Claude

- **Single seller, fun collector shop.** This is one person's cute card shop (tone: light, friendly, never investment talk). Don't add seller accounts, teams, billing, roles, or "sell on our platform" copy. Public pages speak as one shop ("my shop"), never imply other sellers. The only player identity is the reveal game's `Buyer` (a Stripe customer + saved card, signed `ts_player` cookie, no password). A future multi-seller split may change the folder layout; don't build toward it.
- **Packs only; marketplaces never post.** The shop sells three products: Baseball Pack, Football Pack, Pokemon Pack (`lib/categories.ts`; no basketball, no Magic, one tier each). Cards never sell as singles. On upload (`lib/publish.ts`, run from `processBatch`): no name or no photo → hold in Inbox (never invent a name; a filename guess isn't a name); $5 and under → stock (`Priced`); over $5, still sideways, or the same scan twice → **Needs a look** (`NeedsLook`) until the owner approves it in `/admin/queue` (approve = back to stock). The $5 line is dollars, not confidence. Nothing ever posts to eBay, TCGplayer or anywhere else: exports are draft CSVs the owner publishes by hand.
- **The reveal game is the only checkout** (`lib/game/*`, `/packs/[category]`, `/api/play/*`). Rules sentence (`RULES_LINE`) and odds (`oddsLines`) are on screen before the first payment. A saved card is required (Stripe Checkout setup mode via `/play/card`). $1 reveal is charged first, then a ready pack is reserved and all 12 cards are shown with engine prices; 30 s server deadline (+3 s grace), nudge + Keep pulse at 10 s and 20 s (pack graphic only, never the screen). Keep = $2.99 more ($3.99). Pass / timer / leaving the page (sendBeacon) expires the pack for that player (cards back to stock, redrawn), never charges, and locks that category for the account and its card fingerprint until the player's local midnight (`Buyer.tz`). While locked the only action is the $4.99 blind pack: charge first, reserve from the same builder, reveal, no reject; a keep or blind buy clears the lock. One active cycle per account. Off-session PaymentIntents on the saved card, every attempt in `GameCharge`, idempotency key = cycle + kind + attempt; a charge taken with no pack to give is refunded. Payment Links are retired (`retireOldLinks`); the webhook only matches old links.
- **Price rule** (`suggest` + `shopPrice` in `lib/pricing/engine.ts`): one headline per source (sold-comp median, TCGplayer market, Scryfall ask, eBay active median), then the median of those; one source = that number; none = $1. Round to the nearest dollar, min $1; under $1 stays exact. The game never prices a card: pack value = sum of the cards' existing `listPrice`. Sources and disagreement are stored on the card, never shown on the shop (the disclaimers cover it).
- **Shipping:** game packs ship in a tracked bubble mailer; the game prices ($1 / $2.99 / $4.99) include it (no shipping line). Address comes from the save-a-card form (US only). `lib/shipping.ts` rates only apply to old single/pack sales.
- Public pages never list stock. A player sees card names, set, engine price and front image only for a pack reserved to, kept by, or sold to them (`packView`, `/api/play/image/:id` checks `reservedBy`). Every pack page shows the four disclaimers (`lib/disclaimers.ts`).
- Copy: titles plain; descriptions short and friendly (`friendly()` in `lib/listing/templates.ts` drops any sentence with investment, gem-mint or guarantee talk).
- **Pack builder** (`lib/game/rules.ts` pure, `lib/game/packs.ts` DB), per category, never mixed: 12 cards = 8 bulk (< $0.25) + 3 mid ($0.25–$0.75) + 1 top ($0.75–$2.00); summed value must land in $1.80–$2.40 or the draw is thrown out and drawn again; a slot the bins can't fill leaves the category closed (never pad). $2.01–$9.99 cards never go in packs. Never show a pack over $3.50 unless chase (`showable`). Packs are drawn ahead (up to 50 `available` per category) after each batch, reprice, card save and pass; a purchase only reserves an existing pack. `GamePack.status`: available | reserved | kept | expired | sold-blind | dissolved. A card edit dissolves its available pack; reserved/sold packs and their prices are frozen. Card status `LilStack` = in a pack. `category` comes from `categorize()` (Pokemon game → pokemon; sports by league words, full team names, unique nicknames; ambiguous/basketball → null, stays in inventory); a manual category sticks.
- **Chase cards** (≥ $10 engine price, `chaseList`): flag per category in Settings `chaseOn`, default off; can only be turned on once that category has one scanned (`setChase`, Admin → Packs). Off: no $10+ card in any pack, and the odds say "Chase cards are not in packs until that feature is turned on". On: at reservation (same roll for peek and blind) 1 in 25 packs swaps its top card for an eligible chase card (`CHASE_RESERVE_CAP` = 1 chase pack reserved per category at once), and the odds add "About 1 in 25 packs contains a card priced at $10 or more."
- Pack art comes from Gemini (`lib/brandArt.ts`) using `GEMINI_API_KEY` on the server only, from a text prompt. Never send card photos to it. Cached in `DATA_DIR/brand` / bucket `brand/`; missing key = CSS pack, never a broken page.
- **Home** picks a category (Baseball / Football / Pokemon Pack, open or "Restocking") and shows the rules sentence. `/shop` and `/lil-stack` redirect there; `/card/:id` is a 404. The wow score (`lib/wow.ts`) is an admin-only tag.
- Delight (`lib/client/feel.ts`): one short pop on primary buttons, confetti on a keep or blind buy. Respect the Mute toggle and prefers-reduced-motion (nudge and pulse turn off); never block a save on it.
- **Add price/identity sources as adapters** in `lib/sources/` (`IdentifyAdapter` / `PriceAdapter` in `lib/sources/types.ts`), registered in `lib/sources/index.ts`. Adapters fail soft: return `{ status, reason }`, never throw, and skip cleanly when their env key is missing.
- Keep junk out of medians: comps go through `filterComps` (excluded rows are kept and labeled, not deleted). Retail asks (Scryfall, eBay active listings) are their own headlines, never mixed into sold comps.
- Every quote is persisted (`PriceQuote`); only the latest fetch per source drives the suggestion. Manual override always wins.
- Confidence is stored (and highlighted in review) but no longer gates publishing; only a missing name holds a card.
- Scans are private: serve them only via `/api/admin/images/*` (auth) or `/api/play/image/:id` (the player who holds or bought that pack).
- No league, Pokémon, Nintendo, Disney, or other third-party logos in the brand. Colors: navy `#0B1F3A`, teal `#1AA6A6`, sand `#F4EFE6`, coral `#E85D4C`, white.
- Data: Supabase Postgres, schema `trade_shark` (Prisma), and the private `trade-shark-scans` bucket via `lib/storage.ts`. Hosting: Netlify — keep each request short (one card per process call) and send large uploads straight to Storage.
- **Auto-orientation** (`lib/orient.ts`, the first step of `processBatch`, one card per request): every crop is stood upright before identify/price/publish. The vision model says which image edge is the card's top, then re-checks the turned image; the same turn goes to the back; the fixed image is saved over the crop (original kept only for a guess). Without a vision key: landscape crops get a layout guess and wait in Needs a look; portrait is never flipped. Anything still sideways → `holdReason: "rotation"` → Needs a look, never published sideways. Each crop is turned on its own, never the whole sheet. Hand rotation (flatbed "Fallback" panel, queue ↻ buttons, `/api/admin/cards/:id/rotate`) is admin fallback only.
- Flatbed split runs client-side with opencv.js (`lib/flatbed/*`, served from `public/vendor` by `scripts/copy-opencv.mjs`). Never send a whole flatbed sheet to a vision API to split it. Front/back crops pair only by sheet position with identical layouts (`checkSheetPairing`); never guess pairs.
- Checks: `npm test` and `npm run lint` (tsc). Schema changes: edit `prisma/schema.prisma`, run `npx prisma db push` (uses `DIRECT_URL`).
